# Varunetra — National Weather Big Data Analytics Platform

Varunetra is an SIH 2026 demo concept for converting fragmented weather reports into verified, structured, and operational intelligence for India.

## Repository layout

- `next/` — functional Next.js dashboard prototype
- `docs/` — product, architecture, data-source, and presentation notes

## Run the prototype

```bash
cd /home/rdp/Desktop/code/SIH2026/weather_ps/next
npm install
npm run dev
```

Open `http://localhost:3000`.

All visible reports and metrics are simulated for demonstration. The intended production integrations are documented in `docs/data-sources.md`.
